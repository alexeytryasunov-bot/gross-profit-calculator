# Калькулятор валовой прибыли
Калькулятор предназначен для расчёта валовой прибыли, 
наценки и маржи предприятия. В калькуляторе предусмотрены дополнительные расходы, которые влияют на результат прибыли компании.
Имеется память для расчёта разных групп товара.
Ошибочные данные подсвечиваются красным цветов и не вводятся.
Калькулятор позволяет учитывать стоимость доставки.
Ссылка на приложение https://alexeytryasunov-bot.github.io/gross-profit-calculator/
